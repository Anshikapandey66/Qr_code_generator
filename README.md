# QR Code Generator 🔲

A simple Python project that generates QR codes from text or URLs.

## Features

* Generate QR codes from text
* Generate QR codes from URLs
* Save QR code as a PNG image
* Simple and beginner-friendly Python project

## Technologies Used

* Python
* QRCode Library
* Pillow

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python qr_generator.py
```

Enter any text or URL when prompted.

The generated QR code will be saved as:

`my_qr.png`

## Example

Input:

```text
https://github.com/
```

Output:

A QR code image named `my_qr.png`.
